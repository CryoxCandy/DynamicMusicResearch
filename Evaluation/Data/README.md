# Data

Coded answers from the ten paper questionnaires. Participants are identified only by ID (P01–P10); the questionnaire collected no names or contact details.

| File | Contents |
|---|---|
| [`Tetris_Music_Study_Data.xlsx`](Tetris_Music_Study_Data.xlsx) | The working spreadsheet: **Participants** (one row per person), **Ratings** (one row per person per version), **Summary** (live averages and counts) and **Codebook**. Row 2 of Participants and Ratings is a worked data-entry example and is excluded from every calculation. |
| [`participants.csv`](participants.csv) | Participants sheet as CSV (example row removed): order, background answers (Part 1), comparison answers (Part 4, as ticked and mapped to conditions) and written comments. |
| [`ratings.csv`](ratings.csv) | Ratings sheet as CSV: score, game overs, statements a–j, music change, comments and 1–10 rating for each version. |

Data-entry rules: answers are entered as numbers using the codebook below; an unanswered question is left blank (never 0); written answers are copied word for word. *Version A* is always the version played first; the condition it used is recorded per participant, and the Part 4 helper columns convert A/B answers into Adaptive / Static / No difference.

## Codebook

| Question | What it asks | Sheet | Codes |
|---|---|---|---|
| 1.1 | Consent | Participants | 1 = ticked, 0 = not ticked |
| 1.2 | Age | Participants | 1 = 18–24, 2 = 25–34, 3 = 35–44, 4 = 45+, 9 = Prefer not to say |
| 1.3 | How often do you play video games? | Participants | 1 = Never, 2 = Rarely, 3 = A few times a month, 4 = A few times a week, 5 = Daily |
| 1.4 | How much have you played Tetris? | Participants | 1 = Never, 2 = A few times, 3 = Fairly often, 4 = A lot |
| 1.5 | How often is the music on when you play? | Participants | 1 = Never, 2 = Rarely, 3 = Sometimes, 4 = Usually, 5 = Always |
| 1.6 | Musical training | Participants | 1 = None, 2 = Under 2 years, 3 = 2–5 years, 4 = More than 5 years |
| 1.7 | Hearing difficulties | Participants | 0 = No, 1 = Yes, 9 = Prefer not to say |
| 2.1 / 3.1 | Highest score | Ratings | The number as written |
| 2.2 / 3.2 | Times reached Game Over | Ratings | 0, 1, 2, 3 (3 = 3 or more) |
| 2.3 / 3.3 | Statements a–j | Ratings | 1 = Strongly disagree, 2 = Disagree, 3 = Neither, 4 = Agree, 5 = Strongly agree |
| 2.4 / 3.4 | Did the music change? | Ratings | 1 = No, 2 = Yes, a few times, 3 = Yes, often, 9 = Not sure |
| 2.5 / 3.5 | What changed | Ratings | Text, word for word |
| 2.6 / 3.6 | Music rating | Ratings | 1 (Very poor) to 10 (Excellent) |
| 4.1–4.4 | Which version (enjoyed, tense, fit, played better) | Participants | A = Version A, B = Version B, N = No difference |
| 4.5 | Which would you choose at home? | Participants | A = Version A, B = Version B, N = No preference |
| 4.6 | Noticed a difference? | Participants | 1 = No difference, 2 = Slight, 3 = Clear, 9 = Not sure |
| 4.7, 4.8 | Written comments | Participants | Text, word for word |
| Any | Question left unanswered | Either | Leave the cell blank (never 0) |
